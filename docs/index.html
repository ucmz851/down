Engineered For Raw Throughput

[01] POSIX I/O
Lockless Positional Writes

Direct writes to pre-allocated disk sectors via atomic pwrite() and posix_fallocate(). Zero temporary chunk files, zero post-download concatenation delays, and minimal filesystem fragmentation.

[02] SCHEDULER
Dynamic Work-Stealing

Continuously re-balances transfer workloads. When unallocated chunks are depleted, idle workers dynamically bisect the remaining byte ranges of slower connections to eliminate tail-latency stalls.

[03] CRASH RESILIENCE
Zero-Rehash Recovery

Transfer states mirror into a compact memory-mapped control file (.down). Resumes in milliseconds after network drops or unexpected power cuts without re-hashing gigabytes of data.

[04] TRANSPORT
Native HTTP/3 & QUIC

Multiplexed UDP transport via HTTP/3 with automatic protocol negotiation and seamless fallback to HTTP/2 and HTTP/1.1 for universal server compatibility.

[05] CLOUD STORAGE
Direct S3 & R2 Auth

Native AWS Signature Version 4 (AWS4-HMAC-SHA256) signing for s3:// URIs. Access private S3 and Cloudflare R2 buckets without Python, AWS CLI, or external runtimes.

[06] CONCURRENCY
Multi-File Parallel Swarms

Download multiple files concurrently (-j, --concurrent) with dedicated worker pools and a live stacked telemetry dashboard with aggregate bandwidth and unified ETA.

[07] INTERACTIVE
Zero-Flag Setup Wizard

Run down without arguments to launch an interactive terminal setup wizard with beginner-friendly Quick Start and Advanced customization modes.

[08] INTEGRITY
Automated Checksums

Automated hash calculation and verification supporting SHA-256, SHA-512, MD5, SHA-1, and BLAKE2 with automatic algorithm inference from input length.

[09] FOOTPRINT
~120 KB Stripped Binary

Compiled in pure C11 to a standalone executable with negligible memory overhead, relying only on standard system libraries (libcurl, OpenSSL).

Quick Start Guide

1. Launch Interactive Wizard
Zero flags required. Launches a guided setup interface:
$ down
2. Fast Multi-Connection Download
Downloads file using 4 parallel segmented connections:
$ down https://example.com/archive.tar.gz
3. Parallel Multi-File Swarm
Downloads multiple URLs concurrently with unified telemetry:
$ down -j 2 https://ex.com/a.iso https://ex.com/b.iso
4. Direct S3 / Cloudflare R2 Bucket
Native AWS SigV4 signed authorization:
$ down s3://my-bucket/dataset.tar.zst
5. Session History & Resumes
Inspect all past sessions in TSV database:
$ down --history
6. Built-in In-Place Self-Updater
Checks and upgrades to the newest release automatically:
$ down --update
// GET STARTED

Installation Options

Automated Installer (Recommended)

Installs the latest pre-compiled binary with automatic SHA-256 verification on Linux and macOS:

curl -fsSL https://raw.githubusercontent.com/ucmz851/down/main/install.sh | bash

Pre-Built GitHub Releases

Standalone tarballs for Linux x86_64 and macOS (Apple Silicon arm64 & Intel):

tar -xzf down-v0.0.2-linux-amd64.tar.gz install -m 755 down ~/.local/bin/down

Compile From Source

Build natively using GCC/Clang with standard build essentials:

git clone https://github.com/ucmz851/down.git cd down && make -j$(nproc)
